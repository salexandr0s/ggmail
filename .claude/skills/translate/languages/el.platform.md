# el: platform words

The word each platform uses for every label with a platform `msgctxt`. A label keeps its English placeholders and access key as [el.md](el.md) says; the table gives the words.

The table is written from `el.json` beside this sheet, whose `platformWords` rows give each word with its source and the entries it settles by `msgctxt` and `msgid`; the sidecar also holds the banned words, pinned terms and access-key style that `check.ts` holds a catalog against. Change a word in the sidecar, never here, then run `bun .claude/skills/translate/platform-table.ts el`; a test fails while the two differ.

Sources: **AppKit** and **Mail** are the `.loctable` files in `/System/Library/Frameworks/AppKit.framework/Versions/C/Resources` and `/System/Applications/Mail.app/Contents/Resources` on macOS 27, named by table and key; **Software Update** is `/System/Library/ExtensionKit/Extensions/SoftwareUpdateSettingsExtension.appex/Contents/Resources/Localizable.loctable`; **TBX** is the Microsoft Terminology Collection, `GREEK.tbx`, by `termEntry` id; **gtk4**, **nautilus**, **gnome-text-editor** and **gnome-control-center** are GNOME's `el.po` for each, by `msgid` (and `msgctxt` where it has one). _Inferred_ marks a word no source gives for that label, built from the source words named. **WebKit** is `/System/Library/Frameworks/WebKit.framework/Versions/A/Frameworks/WebCore.framework/Versions/A/Resources/<language>.lproj/Localizable.strings`, the page context menu Safari shows, by key; a context-menu item with an access key and no platform `msgctxt` on Windows and Linux takes the house word there, and its `macOS` entry takes Apple's.

Microsoft's Greek gives a verb where its English names a command (_αναιρώ_, _επικολλώ_, _εξάγω_, _εμφανίζω_, _αποκρύπτω_), so the `Windows` label is that verb's action noun, the form every other Greek label takes: _Αναίρεση_, _Επικόλληση_, _Εξαγωγή_, _Εμφάνιση_, _Απόκρυψη_.
